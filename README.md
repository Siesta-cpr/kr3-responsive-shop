## Исправления доступности

- на все страницы добавлена ссылка пропуска «Перейти к основному содержимому», у `main` добавлен `id="main"`;
- текущий пункт меню помечен через `aria-current="page"`;
- добавлен общий видимый фокус `:focus-visible` для ссылок, кнопок и полей формы;
- в таблице характеристик заголовки столбцов и строк размечены через `th` с `scope`.
